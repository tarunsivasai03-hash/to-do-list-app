# My Notes — Notion-style notes app (Android)

A Notion-inspired notes app for Android built with Java, Room, ViewModel/LiveData and Material 3.

## Features
- Notion-style light and dark themes with colored category tags
- Search, category filter and sorting (all combined)
- Pin notes, tappable `[ ]` / `[x]` checklists with progress on cards
- Archive and Trash (auto-deleted after 30 days) with undo
- Reminders with notifications (restored after reboot)
- Share notes, grid / list view

## Build
Open in Android Studio and run, or `./gradlew assembleDebug`.
